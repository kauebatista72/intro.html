O que são formulários?

Os formulários são uma das partes mais importante do nosso HTMLsemãntico. Ele serve para:

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação do envio de informações

Como trabalhar com um form no HTML

Para começarmos a trabalhar com um formulário dentro do HTML, utilizamos o elemento de < form >

Esse elemento, representa um formulário interativo.
