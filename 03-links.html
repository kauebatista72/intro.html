Link externo

Acessar o instagram

Usamos o atributo chamado de target. Esse atributo serve para indicar onde o link configurado no href será aberto.

Algumas ações do target

  • _salf
    • abre na mesma aba. É a configuração padrão.
  • _blank
    • abre o link em uma nova aba/janela.
  • _parent
    • abre no contexto pai, usado com iframe.
  • _top
    • abre no contexto mais externo tambem com iframe
